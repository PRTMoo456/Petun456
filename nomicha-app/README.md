# ปิดยอดโนมิชา — ระบบจริง

ระบบสรุปยอด 5 สาขา (ต่อยอดจากต้นแบบสาธิต) เขียนด้วย Vite + vanilla JavaScript + Supabase (ฐานข้อมูล + ระบบล็อกอิน)

- สเปกทั้งหมด: โปรเจกต์ "สรุปยอดสาขา" ในบัญชี Claude (`claude/concept-spec.md`)
- ต้นแบบสาธิต (ข้อมูลจำลอง): https://claude.ai/code/artifact/81c486e4-218e-4084-a119-8e749717c3b3
- **วิธีติดตั้ง: อ่าน [`docs/DEPLOY.md`](./docs/DEPLOY.md) ทำตามทีละขั้น**

## โครงสร้างโฟลเดอร์

```
supabase/schema.sql              โครงตาราง + Row Level Security ทั้งหมด
supabase/seed_reference_data.sql ข้อมูลจริง (สาขา/วัตถุดิบ/par/รอบส่งของ) ดึงจากต้นแบบตรง ๆ
supabase/migrations/            สคริปต์อัปเดตฐานข้อมูลสำหรับคนที่รัน schema.sql ไปแล้ว
supabase/reset.sql               ⚠ ล้างฐานข้อมูลทิ้งเริ่มใหม่ — ใช้เฉพาะตอนติดตั้งครั้งแรกแล้วรันพลาด
supabase/functions/admin-users/ ตัวช่วยฝั่งเซิร์ฟเวอร์ — สร้างบัญชี/เปลี่ยนรหัสผ่าน (กุญแจผู้ดูแลห้ามอยู่ในหน้าเว็บ)
src/supabaseClient.js            เชื่อมต่อ Supabase (อ่านค่าจาก .env)
src/settings.js                  โหลดค่าคงที่ทางธุรกิจ (ค่าคอมแกร๊บ/ราคาแก้ว/กติกาเงินเดือน ฯลฯ)
src/auth.js                      ล็อกอินด้วยชื่อผู้ใช้+รหัสผ่าน / ออกจากระบบ
src/admin.js                     เรียกตัวช่วยจัดการบัญชี (สร้างบัญชี/เปลี่ยนรหัสผ่าน) + ตรวจชื่อผู้ใช้/เลขบัตรประชาชน
src/pages/people.js              การ์ด "จัดการสาขา" ในตั้งค่าเจ้าของ (ชื่อผู้ใช้/รหัสผ่าน/ชื่อ-นามสกุล/เลขบัตร/เงินเดือน/วันหยุด/ค่าเช่า/เวลาทำงาน/พิกัด)
src/calc.js                      สูตรคำนวณเงินเดือน/กำไรขาดทุน/สต๊อก (พอร์ตจากต้นแบบ ตรวจเทียบด้วยข้อมูลจริงแล้ว)
src/close.js                     ฟอร์มปิดยอด+ตรวจค่า+บันทึก ใช้ร่วมกันทั้งพนักงานและหัวหน้า
src/refs.js                      โหลดข้อมูลอ้างอิง (สาขา/วัตถุดิบ/รอบส่งของ) ที่ทุกหน้าใช้ร่วมกัน
src/dayoff.js                    ปฏิทินจองวันหยุด (ใช้ร่วมกันหน้าพนักงาน/หัวหน้า)
src/geo.js                       ตรวจตำแหน่งก่อนลงเวลา (ลงได้เฉพาะตอนอยู่ในรัศมีร้าน)
src/warehouse.js                 สต๊อกคลังกลาง + ออก/แก้ไข/ยกเลิกบิลขายนอกสาขา
src/print.js                     เอกสารพิมพ์ได้ 5 แบบ (สลิปเงินเดือน/ใบส่งของ/บิลขายนอก/สรุปทั้งเดือน)
src/pages/staff.js               หน้าพนักงานสาขา (เสร็จแล้ว — 3 แท็บ)
src/pages/relief.js              หน้าหัวหน้า (เสร็จแล้ว — 5 แท็บ)
src/pages/owner.js               หน้าเจ้าของ (เสร็จแล้ว — 7 แท็บ)
test/                            ชุดทดสอบ — รันหน้าจอจริงทั้ง 3 บทบาททุกแท็บด้วยข้อมูลจำลอง (npm test)
docs/DEPLOY.md                   ขั้นตอนติดตั้งแบบทำตามได้เอง + สถานะงานล่าสุด + จุดที่ตัดทอนไว้
```

## ทดสอบ

```
npm test        # รันทุกหน้าจอ ตรวจว่าไม่มี error / ไม่มี NaN บนจอ / ตัวเลขเชื่อมโยงกันถูกต้อง (33 ชุด)
```
ทดสอบนี้ไม่ต้องต่อ Supabase จริง (ใช้ฐานข้อมูลจำลองใน `test/mockdb.mjs` ที่ชื่อคอลัมน์ตรงกับ `schema.sql` เป๊ะ)
แนะนำให้รันด้วยเขตเวลาไทยด้วย: `TZ=Asia/Bangkok npm test`

## รันทดสอบในเครื่อง (ถ้าอยากลองก่อน deploy)

```
npm install
cp .env.example .env   # แล้วกรอกค่า Supabase จริง
npm run dev
```
